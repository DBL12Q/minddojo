# 思维塾 MindDojo

> 读不是目的，练才是。

把《逻辑思维》（[美]理查德·尼斯贝特 著）里的思维工具，整理成可以每天练习的卡片与清单。本站为**学习型衍生项目**：所有工具说明、例子与练习均为原创二次创作，未搬用原书原文；原书版权归作者及出版社所有。

## 功能（v0.1.0 MVP）

- 🧰 **工具地图**：30 个思维工具，六个板块（看人 / 算账 / 看数据 / 验证 / 推理 / 判断可信度）
- 🎯 **每日一练**：每天随机抽取一个练习，练完打卡
- 🛡️ **陷阱检测**：24 道场景题，随机抽 20 道，测完出成绩单
- 📊 **我的清单**：练习打卡、工具标记（已做到 / 待做 / 收藏）、板块进度分

## 技术栈

纯前端静态站：HTML + CSS + 原生 JavaScript（hash 路由），数据存浏览器 localStorage，无需后端、无需登录。

## 本地运行

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后浏览器打开 `http://localhost:8000`。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `minddojo`），设为 Public；
2. 将本目录文件推送到仓库（或直接用 `gh-pages` 分支）；
3. 仓库 Settings → Pages → Source 选择分支 → 保存，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 统计（可选）

部署后如需统计访问用户数，可在 `index.html` 的 `<head>` 中加入一行统计脚本：
- Cloudflare Web Analytics（免费，无后端）：`https://static.cloudflareinsights.com/beacon.min.js`
- 或百度统计（国内）：在 `script` 中配置 `hm.js`。
